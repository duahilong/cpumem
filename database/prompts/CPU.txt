本图是 CPU 报价单，专用规则：

【核心：先识别行结构，再对应价格】
图中 CPU 表格有两种价格结构，必须先判断属于哪种：

结构A【双型号行】：一行列两个或多个型号（型号名用 / 或 - 分隔），价格在旁边或下一行
  - 对应规则：第1个型号 ↔ 第1个价格，第2个型号 ↔ 第2个价格（按水平/顺序位置一一对应）
  - 例："i3 10100F/10105F" 配价格 "345/370" → 10100F=345，10105F=370（两条记录，price_type 相同，由该区域列头决定）
  - 例："U5 230F/245KF/245K" 配价格 "12/85/238" → 230F=12，245KF=85，245K=238（三条记录）
  - 注意：此时两个型号的价格通常【不同】，如果输出了两条相同价格的记录，说明对应错了

结构B【单型号双价】：一行只有一个型号，对应两个价格
  - 对应规则：第1个价格 = 散片（price_type="散片"），第2个价格 = 盒装/原盒（price_type="原盒"）
  - 例："i5 10400F 620/655" → 620散片 + 655原盒（两条记录）
  - 有些型号的散片价和盒装价显示在不同位置/行，也要分别提取为两条记录

判断方法：数一数这一行（或这两行）里有几个型号名、几个价格：
- 型号数 > 1 → 结构A（按位置对应型号，price_type 由区域列头统一决定）
- 型号数 = 1 且价格数 = 2 → 判断该行是"散片+原盒"还是"两个散片价"：
  - 散片/原盒两列分别有价且价格差异明显（相差 10% 以上）→ 结构B，输出两条（散片 + 原盒）
  - 两个价格几乎相同（相差不到 10%）→ 是同行两个散片价（不同渠道），取第 1 个价格输出一条散片记录
  - 例："i5 14400 975/980"、"i5 14600KF 1550/1570"、"i7 14700KF 2090/2205"、"i3 12100F 610/618"、"i3 12100 728/732" 两价接近 → 只输出散片第1价
  - 例："i5 13400F 817/920"、"i5 13490F 809/975" 价差明显 → 输出散片 + 原盒两条

【严禁两类错误】
1. 【严禁把结构A当结构B】双型号行不是"一个型号的散片/原盒"！如 "i3 10100F/10105F 345/370" 是 10100F=345 和 10105F=370 两个不同型号的价格，绝不是 10100F 的散片和原盒
2. 【严禁行错位/列复制】每行的价格只属于该行型号；不要把某行高亮/特价的值复制给同列其他行；相邻型号（如 12400 与 12400F、12700 与 12700KF）价格不同，必须水平对齐
3. 【严禁整体 shift 错位】输出前自检：如果发现"连续多个型号的价格序列整体向下/向上错了一行"（如 12600K 拿到 12700F 的价、12700F 拿到 12700KF 的价、12700KF 拿到 12700 的价），说明整列错位，必须重新逐行水平对齐。自检方法：确认每个价格正上方的型号名就是该价格对应的型号

【价格量级校验】
- i3/老款奔腾散片：几百元；i5/U5 散片：几百到一千元；i7/U7 散片：一千到两千；i9/U9 散片：两千以上
- 价格与型号定位明显不符（如 U9 只有几百元），说明对齐错了，跳过该行

【型号边界识别】
- U5/U7/U9、i3/i5/i7/i9、Ryzen、G 开头（奔腾）是新型号的标志
- 型号名里的"-"连接的是同一型号的规格（如 i5-13400F），不是型号分隔符
- 对应关系不确定时，直接跳过，不要猜测
- 型号名保留完整规格（如 "i5 13400 10核16线程 2.5/4.6"）
- 同一个型号在不同区块出现时，分别提取为多条记录

【U 系区域特别注意】
- intel 15/14 代（U 系）区域经常【散片列为空，只有原盒列有价】。判断 price_type 必须看价格所在的列头：价格在"原盒"列下方就是原盒，在"散片"列下方才是散片。不要默认全部标散片，也不要默认全部标原盒
- 该区域很多型号该期无价（价格栏空白），空白行直接跳过，绝不把其他行的价格复制给它
- 该区域常出现"一行多个型号 + 下一行多个价格"或"同行多价格"的结构，严格按位置一一对应
- 注意：U9 285K 等型号的价格常在【散片列】（如 285K 散片 2820），价格在散片列头正下方就必须标散片；逐行看列头，不要凭"U系都是原盒"的惯性判断

【K / KF / 无后缀 是三个不同型号】
- 图中常见连续三行：如 i5 12600K、i5 12600KF（或 i7 12700K、12700KF）。K、KF、无后缀（纯数字）是不同的型号，价格各不相同
- 每一行的价格严格水平对齐到该行的型号，绝不串行
- 输出前自检：如果发现"12600K 和 12600KF 价格相同"或"12700F 拿到了 12700KF 的价格"，说明串行了，重新对齐

【双型号行拆分自检】
- "i3 10100F/10105F 345/370" 结构：第一个价格属于第一个型号，第二个价格属于第二个型号
- 自检：拆分后每个型号一个价格，且价格不同（如果两个型号输出了相同价格，说明拆错了）

【第2轮强化规则】
1. 【price_type 默认判断】intel 15/14 代（U 系）区域的价格大多数在"原盒"列。如果该区域"散片"列看起来是空的、价格都集中在另一列，那一列就是原盒列，所有价格标 price_type="原盒"。判断不了时标原盒，不要默认散片
2. 【无后缀版与 F 版是两行】图中常见连续两行：第一行是 F 版（如 I3 14100F），第二行是无后缀版（如 I3 14100）。它们是不同型号、价格不同。图中如果两行都存在（各自有价格），必须输出两条记录，缺一不可。同样适用于 13400F/13400、14400F/14400、14600KF/14600K、14700F/14700 等所有配对
   自检：如果输出了 14100F 但没有 14100，回看图中是否还有一行无后缀的 14100 及它的价格，有就补上
3. 【不要漏掉边角型号】表格第一栏（intel 老款处理器）的最后一行（如 "Inte 300 (14代奔腾) 替代G7400 500"）也是有效数据，不要遗漏
